# Roadmap

v0.1.0 发布现有 alpha，并提供可复现演示；未把第二轮待办记为已完成。
修复前后必须使用同一 `selection.json` 评测，分别报告定位率、完整提取率和运行耗时。

## P0：防止双 Y 轴数值误用

- 读取右轴刻度并建立 `Panel.y2`，按轴颜色、图例和样式分配 `Series.axis`。
- 归属不确定时明确提示或拒绝输出该系列，避免默认为左轴。
- 接通 JSON/预览中的右轴信息，并增加合成双轴真值及真实失败案例回归。
- 初始复现：评测报告中 `B84X8NKW` p14。不能以“检测到双轴”作为归属正确的验收。

## P1：曲线提取正确性

- 碎线合并与整曲线去重，避免一条曲线拆成多个系列或不同曲线被合并。
- 单线段绘制、锯齿填充轮廓中心线和空心标记分组。
- 剔除轮廓字、注释和插图，复核曲线/标记/误差棒关系。
- 固化报告里的失败案例，再重跑真实样本；不以增加系列数作为改进指标。

## P2：识别覆盖与速度

- 标签存在但标定失败的图、旋转轮廓标签、无轴线图和共用轴堆叠图。
- 位图/热图误检过滤；无 y 数值的图如需归一化，必须标记人为尺度。
- 改进图例命名和轴标题；优化大路径数页面，报告中位数与最慢页面。
